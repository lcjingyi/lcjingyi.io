GoLnk — 桌面快捷方式管理工具

使用 Go + Wails v2 + Vue 3 构建的 Windows 桌面快捷方式管理工具

📋 项目信息

项目 值
开发语言 Go 1.24 + Vue 3 (Vite)
桌面框架 Wails v2.12.0
目标平台 Windows 10/11 (amd64)
构建工具 wails build
数据存储 %APPDATA%/GoLnk/ (JSON 文件)
窗口 1280×800, 最小 900×600, 暗色背景 #1B2636

关键交互

操作 触发方式 效果
打开程序 点击「▶ 打开」按钮 / 右键菜单 ShellExecuteW 启动
定位文件 点击「📂 定位」按钮 / 右键菜单 资源管理器打开
删除 鼠标悬停右上角 ✕ / 右键菜单 从缓存移除
更改分类 点击分类标签 / 右键菜单 弹出分类选择器
新建快捷方式 空白区域右键 / 顶部「➕ 新建」按钮 弹窗填写路径
管理分类 顶部「🏷️ 分类」按钮 / 空白区域右键 弹窗增删
搜索 顶部搜索框输入 实时过滤名称+路径
刷新 顶部「⟳ 刷新」按钮 / 空白区域右键 重新扫描桌面
